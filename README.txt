BIRTHDAY SURPRISE WEBSITE
=========================

This is a frontend-only birthday surprise website.
No database, backend, API or login is required.

QUICK START
-----------
1. Open index.html directly in Chrome/Edge, OR serve this folder with any simple web server.
2. The experience starts immediately.

PERSONALIZE THE WEBSITE
-----------------------
Open birthday-content.js in Notepad or VS Code.
Change the values inside BIRTHDAY_CONTENT.

You can edit:
- recipientName
- intro greeting/message/button
- balloon text
- candle text
- bouquet text
- complete love letter
- gift text
- final birthday message
- signature

The main website code does not need to be changed for normal text personalization.

IMPORTANT
---------
The website currently uses CSS/SVG-like illustrations created in code, so there are no image files you need to manage.
Google Fonts are loaded when the page has internet access; the website still works if fonts cannot be loaded.

DEPLOYMENT
----------
You can upload index.html and birthday-content.js to a static hosting service such as:
- Vercel
- Netlify
- GitHub Pages
- Cloudflare Pages

If you later want custom photos, music, or exact artwork from the reference video, we can add an assets folder and connect those files.
